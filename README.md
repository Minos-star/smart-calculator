# 🧮 智能计算器 (Smart Calculator)

## ✨ 功能特点

- ✅ 支持加、减、乘、除四则运算
- ✅ 支持连续计算（如：1+2=3，然后 +5=8）
- ✅ 显示最近10条计算历史记录
- ✅ 完善的异常处理（除零保护、非法输入保护）
- ✅ 友好的命令行交互界面
